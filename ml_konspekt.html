KNN — K-Nearest Neighbors

“Qo'shningni ayt, kimsanligingni aytaman.” KNN — Instance-based (misollarga asoslangan) va Lazy Learning (dangasa) algoritmi. fit()da hech qanday formula qurmaydi — shunchaki ma'lumotni xotirada saqlaydi. Barcha hisob-kitob predict()da bo'ladi.

🔍 Qanday ishlaydi?

📐 Matematik asosi — Evklid masofasi

d(x,y) = √ Σi=1..n (xi − yi)2

Ikki nuqta orasidagi “to'g'ri chiziqli” masofa. metric='minkowski', p=2 aynan shu Evklid masofasini bildiradi (p=1 bo'lsa — Manhattan masofasi).

⚠️ O'ta muhim shart — Scaling MAJBURIY! KNN masofaga tayanadi. Agar maosh ustuni 10 000 000 va yosh ustuni 25 bo'lsa, masofa deyarli faqat maoshga bog'liq bo'lib qoladi — yosh butunlay “yutib yuboriladi”. Shuning uchun StandardScaler yoki MinMaxScaler shart.
✅ Afzalliklari
  • Juda oddiy, tushunarli
  • O'qitish bosqichi yo'q (lazy)
  • Ko'p sinfli masalalarga mos
⚠️ Kamchiliklari
  • Katta datasetda juda sekin (predict)
  • Scaling shart
  • Curse of Dimensionality (ko'p ustunda buziladi)
knn.py
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier, KNeighborsRegressor

# Klassifikatsiya uchun — Scaler + KNN bitta pipeline'da
pipe_cls = Pipeline([
    ('scaler', StandardScaler()),                 # scaling MAJBURIY
    ('knn', KNeighborsClassifier(n_neighbors=5, metric='minkowski', p=2))
])
pipe_cls.fit(X_train, y_train)                     # faqat xotiraga saqlaydi

# Regressiya uchun — qo'shnilarning o'rtacha qiymati olinadi
pipe_reg = Pipeline([
    ('scaler', StandardScaler()),
    ('knn', KNeighborsRegressor(n_neighbors=5))
])
pipe_reg.fit(X_train, y_train)

SVM — Support Vector Machine

“Eng keng yo'lakni topaman.” KNN har bashoratda butun datasetni ko'radi. SVM esa faqat chegaradagi eng muammoli nuqtalarni — Support Vectorlarni — saqlab, ular orasidan eng keng Margin (yo'lak) o'tkazadi.

Faqat aylana ichidagi “tayanch vektorlar” chegarani belgilaydi — qolgan nuqtalar ahamiyatsiz.

⚙️ Asosiy giperparametrlar

C (Jazo kuchi):
• Kichik C → keng yo'lak, ba'zi xatolarga ko'z yumadi (Underfitting xavfi).
• Katta C → tor yo'lak, xatoga toqat qilmaydi (Overfitting xavfi).
gamma (rbf/poly uchun):
Har bir nuqtaning ta'sir doirasi.
• Katta gamma → tor ta'sir (murakkab chegara).
• Kichik gamma → keng, silliq chegara.

🌀 Kernel Trick (Yadro usuli)

Chiziqli ajratib bo'lmaydigan 2D ma'lumotni matematik tarzda yuqori o'lchamli fazoga (3D) ko'chirib, u yerda oddiy tekislik bilan ajratadi. Variantlari: linear, poly, rbf (Radial Basis Function — eng ko'p ishlatiladi).

Scaling: SVM ham masofaga tayanadi → StandardScaler shart.
svm.py
from sklearn.svm import SVC, SVR
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline

# Klassifikatsiya (SVC) — rbf kernel bilan
svm_cls = Pipeline([
    ('scaler', StandardScaler()),
    ('svm', SVC(C=1.0, kernel='rbf', gamma='scale', probability=True))
])
svm_cls.fit(X_train, y_train)

# Regressiya (SVR)
svm_reg = Pipeline([
    ('scaler', StandardScaler()),
    ('svm', SVR(C=1.0, kernel='rbf'))
])
svm_reg.fit(X_train, y_train)

Decision Tree — Qaror Daraxti

KNN va SVM masofaga tayanadi va scaling talab qiladi. Decision Tree esa masofani umuman hisoblamaydi — u ketma-ket IF-ELSE qoidalarini tuzadi. Scaling talab etilmaydi!

📐 Bo'linish qanday tanlanadi? (Gini & Entropy)

Daraxt eng toza (pure) guruhlarni hosil qiladigan ustun va chegarani qidiradi.

Gini = 1 − Σ(pi)2

0 — toza guruh, 0.5 — to'liq aralash. Hisoblash tez.

Information Gain: ota tugun va bola tugunlar orasidagi tozalik farqi. Daraxt eng katta gain beruvchi splitni tanlaydi.

✂️ Overfitting'ga qarshi kurash (Pruning)

Cheklovsiz daraxt har nuqta uchun alohida barg ochib, train'ni yodlab oladi (Train Acc = 100%, Test = 60%). Nazorat parametrlari:

  • max_depth — daraxtning maksimal chuqurligi.
  • min_samples_leaf — bargda qolishi kerak bo'lgan minimal namunalar soni.
decision_tree.py
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor

# Klassifikatsiya — scaling SHART EMAS
dt_cls = DecisionTreeClassifier(max_depth=4, min_samples_leaf=5,
                                criterion='gini', random_state=42)
dt_cls.fit(X_train, y_train)

# Regressiya
dt_reg = DecisionTreeRegressor(max_depth=4, min_samples_leaf=5, random_state=42)
dt_reg.fit(X_train, y_train)

Random Forest — Bagging

Bitta daraxt beqaror — ma'lumot biroz o'zgarsa, butunlay boshqa daraxt chiqadi (yuqori variance). Random Forest 100–200 ta mustaqil daraxt jamoasini tuzib, ovozga qo'yadi (Bootstrap Aggregating = Bagging).

🎲 Ikkita tasodifiylik manbasi

  • Bootstrap Sampling: har bir daraxt uchun datasetdan o'rniga qo'yish (with replacement) bilan tasodifiy namunalar olinadi.
  • Random Feature Selection: har bir bo'linishda barcha ustunlar emas, faqat tasodifiy √N ta ustun ko'riladi → daraxtlar bir-biriga o'xshamaydi.
random_forest.py
from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor

# Klassifikatsiya — n_jobs=-1 barcha CPU yadrolarini ishlatadi (parallel)
rf_cls = RandomForestClassifier(n_estimators=100, max_depth=6,
                                max_features='sqrt', random_state=42, n_jobs=-1)
rf_cls.fit(X_train, y_train)

# Regressiya
rf_reg = RandomForestRegressor(n_estimators=100, max_depth=6, random_state=42, n_jobs=-1)
rf_reg.fit(X_train, y_train)

Bagging vs Boosting — Variance vs Bias

Ansambl modellari ikki asosiy yo'nalishga bo'linadi. Farqni tushunish — barcha keyingi modellar (GBM, XGBoost) mantig'ini tushunish kaliti.

Xususiyat🔹 Bagging (Random Forest)🔸 Boosting (AdaBoost, GBM, XGBoost)
Daraxtlar holatiParallel, bir-biridan mustaqilKetma-ket, bir-biriga bog'liq
MaqsadiVariance↓ (shovqinni o'rtachalash)Bias↓ (tizimli xatoni tuzatish)
Daraxt turiChuqur, murakkab daraxtlarKichik, zaif daraxtlar (stumps, max_depth=1..3)
Overfitting xavfiDaraxt sonini oshirish overfit qilmaydiDaraxt soni oshib ketsa overfit bo'lishi mumkin
Bir jumlada: Bagging — “ko'p mustaqil ekspert ovoz beradi” (beqarorlikni yo'qotadi); Boosting — “bir ekspert xatosini keyingisi tuzatadi” (aniqlikni oshiradi).

Uzilgan Zanjir Ko'prigi: Gradient & Residual

Boosting'ning eng muhim g'oyasi: “Keyingi model oldingi modelning XATOSINI o'rganadi.” Buni tushunish uchun ikki tushuncha kerak: Gradient Descent va Residual.

6.1 Gradient Descent nima?

Loss (xato) funksiyasining minimum nuqtasini topish usuli. Xatoni kamaytirish uchun gradientga (hosilaga) teskari tomonga learning_rate qadamlari bilan tushib boramiz:

θyangi = θeski − η · ∂Loss/∂θ

6.2 Residual (Qoldiq xato) nima?

Residual = y (haqiqiy) − ŷ (bashorat)

MSE loss funksiyasining hosilasi (gradienti):

∂Loss/∂ŷ = −2(y − ŷ) = −2 · Residual
💡 Xulosa: Gradientning teskarisi (−Gradient) to'g'ridan-to'g'ri Residualga teng! Demak, Gradient Boosting har safar gradientni bashorat qilishi — regressiyada oddiy qoldiq xatoni (Residual) bashorat qilish demak.

🔢 Qadam-baqadam sonli misol

Haqiqiy qiymat y = 100, learning rate η = 0.1.

  1. F0 (boshlang'ich): o'rtacha qiymat ŷ = 80 → Residual = 100 − 80 = +20
  2. Tree 1: +20 ni o'rganadi va +12 beradi → yangi bashorat = 80 + 0.1×12 = 81.2
  3. Tree 2: qolgan residualni (100 − 81.2 = 18.8) o'rganishda davom etadi...
  4. Har bir daraxt qoldiqni bosqichma-bosqich kamaytirib, bashoratni 100 ga yaqinlashtiradi.

AdaBoost va Gradient Boosting (GBM)

1️⃣ AdaBoost (Adaptive Boosting)

Xatoni namuna vaznlarini (weights) o'zgartirish orqali tuzatadi. Birinchi model xato qilgan nuqtalarning vazni oshiriladi → keyingi model o'sha “og'ir” nuqtalarga ko'proq e'tibor beradi.

2️⃣ Gradient Boosting (GBM)

Xatoni vazn orqali emas, to'g'ridan-to'g'ri Residual / Gradientni bashorat qilish orqali tuzatadi (6-bo'limdagi mantiq).

boosting.py
from sklearn.ensemble import (AdaBoostClassifier, GradientBoostingClassifier,
                             GradientBoostingRegressor)

# AdaBoost — vaznlarni qayta taqsimlaydi
ada = AdaBoostClassifier(n_estimators=50, learning_rate=0.1, random_state=42)
ada.fit(X_train, y_train)

# Gradient Boosting Classifier — residualni bashorat qiladi
gb_cls = GradientBoostingClassifier(n_estimators=100, learning_rate=0.1,
                                    max_depth=3, random_state=42)
gb_cls.fit(X_train, y_train)

# Gradient Boosting Regressor
gb_reg = GradientBoostingRegressor(n_estimators=100, learning_rate=0.1,
                                   max_depth=3, random_state=42)
gb_reg.fit(X_train, y_train)

Modelni Upgrade qilish: Grid & Random Search

Giperparametrlarni qo'lda qidirish samarasiz. Avtomatlashtirilgan qidiruv (Hyperparameter Tuning) + Cross-Validation (CV) ishlatamiz.

GridSearchCV: ko'rsatilgan parametrlarning BARCHA kombinatsiyasini birma-bir sinaydi. Aniq, lekin sekin (kombinatsiya ko'p bo'lsa).
RandomizedSearchCV: parametr fazosidan TASODIFIY kombinatsiyalar tanlaydi. Tez va katta maydon uchun samarali.
tuning.py
from sklearn.model_selection import GridSearchCV, RandomizedSearchCV
from sklearn.ensemble import GradientBoostingClassifier

param_grid = {
    'n_estimators': [50, 100, 200],
    'learning_rate': [0.01, 0.1, 0.2],
    'max_depth': [3, 4, 5]
}

grid = GridSearchCV(
    estimator=GradientBoostingClassifier(random_state=42),
    param_grid=param_grid,
    cv=5,               # 5-fold cross-validation
    scoring='f1',       # yoki 'roc_auc'
    n_jobs=-1           # barcha CPU yadrolari
)
grid.fit(X_train, y_train)

print("Eng yaxshi parametrlar:", grid.best_params_)
best_model = grid.best_estimator_

XGBoost — eXtreme Gradient Boosting ⭐

XGBoost — Gradient Boosting'ning optimallashtirilgan, o'ta tez va aniq “sport mashinasi” versiyasi. Mantiq bir xil (residualni tuzatish), lekin tezlik, aniqlik va overfitting nazorati uchun ko'plab kuchli yaxshilanishlar qo'shilgan. Kaggle'ning “chempioni”.

🔑 XGBoost'ning 3 asosiy afzalligi — batafsil

1 · Hessian (2-tartibli hosila)

Oddiy GBM faqat 1-hosila (Gradient)ni ishlatadi — ya'ni “qaysi tomonga tushish kerak”. XGBoost esa 2-hosila (Hessian)ni ham hisobga oladi — ya'ni “naqadar tik tushish kerak” (egrilik). Bu Nyuton usuliga o'xshab, minimumga tezroq va aniqroq yetadi. Xuddi mashinada faqat gaz emas, balki yo'lning burilishini ham ko'rib haydash kabi.

2 · Built-in Regularization (L1 & L2)

Loss funksiyasiga model murakkabligi uchun jarima qo'shadi: reg_alpha (L1, γ) va reg_lambda (L2, λ). Bu daraxtlar juda murakkab bo'lib train'ni yodlab olishining (Overfitting) oldini oladi. Aynan shu narsa XGBoost'ni oddiy GBM'dan ustun qiladi.

Obj = Σ Loss(y, ŷ) + Σ [ γ·T + ½λ·w² ]

Chapda — aniqlik (loss), o'ngda — jarima: T = barglar soni, w = barg qiymatlari. Bu balans XGBoost sirining kaliti.

3 · Parallellik + Tree Pruning + Missing values
  • Parallellik: boosting ketma-ket bo'lsa-da, bitta daraxt ichida split qidirishni ustunlar bo'yicha parallellashtiradi → ancha tez.
  • Tree Pruning: manfiy “gain” beruvchi (foydasiz) shoxlarni kesib tashlaydi.
  • Missing values: bo'sh qiymatlarni qaysi tomonga yuborishni o'zi o'rganadi — alohida to'ldirish shart emas.
❓ subsample=0.8 va colsample_bytree=0.8 nima degani? (Sizning savolingiz)

Bu ikkalasi — overfitting'ga qarshi “tasodifiylik” qo'shuvchi parametrlar. Xuddi Random Forest kabi, har bir daraxtga ma'lumotning faqat bir qismini beramiz — shunda daraxtlar bir-biriga o'xshamaydi va model umumlashtiradi (generalize).

• subsample=0.8 → QATORLAR (satrlar / namunalar): har bir daraxtni qurishda datasetdagi satrlarning 80%i tasodifiy tanlanadi, 20%i o'sha daraxt uchun tashlab qo'yiladi. Ya'ni 1000 ta mijozdan har daraxt faqat tasodifiy 800 tasini ko'radi.

• colsample_bytree=0.8 → USTUNLAR (features / xususiyatlar): har bir daraxt uchun ustunlarning 80%i tasodifiy tanlanadi. Ya'ni 10 ta ustundan har daraxt faqat tasodifiy 8 tasini ishlatadi.

Nega 0.8? Chunki 1.0 (100%) → hamma daraxt bir xil ma'lumotni ko'radi → o'xshab qoladi va overfit bo'ladi. 0.8 esa xilma-xillik beradi, aniqlikni oshiradi va tezlashtiradi. Odatda 0.7–0.9 oralig'i tanlanadi.
xgboost_model.py
from xgboost import XGBClassifier, XGBRegressor

# Klassifikatsiya
xgb_cls = XGBClassifier(
    n_estimators=200,        # daraxtlar (bosqichlar) soni
    learning_rate=0.05,      # har bir daraxt hissasi ('qadam')
    max_depth=4,             # har daraxtning chuqurligi
    subsample=0.8,           # QATORLARning 80%i har daraxtga (overfit↓)
    colsample_bytree=0.8,    # USTUNLARning 80%i har daraxtga (RF kabi, overfit↓)
    reg_alpha=0.1,           # L1 regularizatsiya
    reg_lambda=1.0,          # L2 regularizatsiya
    eval_metric='logloss', random_state=42
)
xgb_cls.fit(X_train, y_train)

# Regressiya
xgb_reg = XGBRegressor(n_estimators=200, learning_rate=0.05, max_depth=4,
                       subsample=0.8, colsample_bytree=0.8, random_state=42)
xgb_reg.fit(X_train, y_train)

To'liq Pipeline — EDA'dan Upgrade'gacha

Bu bo'lim — qayta ishlatiladigan shablon. Har bir bosqich alohida, sarlavhasida “nima qilyapmiz” yozilgan. Keyinchalik yangi model qurmoqchi bo'lsangiz, shu tartibni saqlab, faqat dataset va modellarni almashtirasiz. Ichida def va for ishlatilgan — tezkor va toza.

Pipeline tartibi (xotirada saqlang):
1 Import → 2 Data Load → 3 EDA (tanishish) → 4 Preprocessing (tozalash/encode/scale) → 5 Train-Test Split → 6 Baseline (barcha modelni solishtirish) → 7 Tuning (GridSearch) → 8 Final baholash + saqlash.

STEP 1 Import — barcha kutubxonalar

Nima qilamiz: kerakli barcha kutubxonalarni bir joyda import qilamiz.

STEP 2 Data Loading — ma'lumotni yuklash

Nima qilamiz: datasetni yuklaymiz, target va feature'larni ajratamiz.

STEP 3 EDA — ma'lumot bilan tanishish

Nima qilamiz: ma'lumotni “ko'zdan kechiramiz” — o'lcham, bo'sh qiymatlar, tur, target balansi. Buni funksiya qilib olamiz (qayta ishlatish uchun).

pipeline_step3_eda.py
# def bilan qayta ishlatiladigan EDA funksiyasi
def explore_data(df, target):
    print("O'lcham (shape):", df.shape)
    print("\n--- Birinchi 5 satr ---")
    print(df.head())
    print("\n--- Ustun turlari ---")
    print(df.dtypes)
    print("\n--- Bo'sh (NaN) qiymatlar ---")
    print(df.isnull().sum())
    print("\n--- Target balansi (imbalanced tekshirish) ---")

    print("\n--- Statistika ---")

explore_data(df, TARGET)
Nega muhim: value_counts(normalize=True) target balansini ko'rsatadi. Agar 95%/5% bo'lsa → imbalanced → metrika sifatida F1 yoki ROC-AUC tanlaymiz (Accuracy emas!).

STEP 4 Preprocessing — tozalash, encode, scale

Nima qilamiz: raqamli ustunlarni to'ldirib (impute) + masshtablab (scale), kategorial ustunlarni raqamga aylantiramiz (encode). Hammasini bitta ColumnTransformerda avtomatlashtiramiz.

pipeline_step4_prep.py
# Ustunlarni turiga qarab avtomatik ajratamiz
num_cols = X.select_dtypes(include=["int64", "float64"]).columns.tolist()
cat_cols = X.select_dtypes(include=["object", "category"]).columns.tolist()

# Raqamli quvur: bo'sh qiymatni median bilan to'ldir + StandardScaler
num_pipe = Pipeline([
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler())
])
# Kategorial quvur: bo'sh qiymatni eng ko'p uchraydigan bilan to'ldir + OneHot
cat_pipe = Pipeline([
    ("imputer", SimpleImputer(strategy="most_frequent")),
    ("encoder", OneHotEncoder(handle_unknown="ignore"))
])

preprocessor = ColumnTransformer([
    ("num", num_pipe, num_cols),
    ("cat", cat_pipe, cat_cols)
])

STEP 6 Baseline — barcha modellarni solishtirish

Nima qilamiz: 3 ta modelni o'qitamiz, vaqtni o'lchaymiz, barcha metrikalarni hisoblaymiz. def bilan tezkor funksiya yozamiz — yangi model qo'shish oson.

pipeline_step6_baseline.py
# 1. Modellarni lug'at (dict) shaklida e'lon qilamiz — keyin yangisini qo'shish oson
models = {
    "Gradient Boosting": GradientBoostingClassifier(random_state=42),
    "Random Forest":     RandomForestClassifier(random_state=42),
    "XGBoost":           XGBClassifier(random_state=42, eval_metric='logloss')
}

# 2. def — bitta modelni o'qitib, metrikalarni hisoblovchi funksiya
def evaluate_model(name, model, X_tr, X_te, y_tr, y_te):
    start = time.time()
    model.fit(X_tr, y_tr)                                    # o'qitish
    elapsed = time.time() - start

    y_pred  = model.predict(X_te)                            # sinf bashorati (0/1)
    y_proba = model.predict_proba(X_te)[:, 1]                 # ehtimollik (ROC-AUC uchun)

    return {
        "Model": name,
        "Accuracy":  accuracy_score(y_te, y_pred),
        "Precision": precision_score(y_te, y_pred),
        "Recall":    recall_score(y_te, y_pred),
        "F1-Score":  f1_score(y_te, y_pred),
        "ROC-AUC":   roc_auc_score(y_te, y_proba),
        "Time (s)":  elapsed
    }

# 3. for — barcha modellarni aylanib, natijalarni ro'yxatga olamiz
results = []
for name, model in models.items():
    result = evaluate_model(name, model, X_train_scaled, X_test_scaled, y_train, y_test)
    results.append(result)
    print(f"✅ {name} — F1={result['F1-Score']:.3f}, ROC-AUC={result['ROC-AUC']:.3f}")

# 4. Natijalarni DataFrame shaklida chiqarish
df_results = pd.DataFrame(results)
print("\n--- MODEL COMPARISON (Baseline) ---")
print(df_results.to_string(index=False))
Nima qilyapmiz: evaluate_model funksiyasi istalgan modelni olib, o'qitib, 6 ta metrikani hisoblab beradi. for bilan barcha modellarni avtomatik solishtiramiz. Yangi model qo'shish uchun models lug'atiga qator qo'shing — xolos.

STEP 7 Tuning — GridSearchCV bilan giperparametr sozlash

Nima qilamiz: har bir model uchun alohida parametrlar maydoni (dict) belgilab, for bilan ketma-ket tuning o'tkazamiz. Eng yaxshi modelni olamiz.

pipeline_step7_tuning.py
# 1. Har bir model uchun alohida parametrlar lug'ati
param_grids = {
    "Gradient Boosting": {
        'n_estimators': [100, 150],
        'learning_rate': [0.05, 0.1],
        'max_depth': [3, 4]
    },
    "Random Forest": {
        'n_estimators': [100, 200],
        'max_depth': [10, 15],
        'min_samples_split': [2, 5]
    },
    "XGBoost": {
        'n_estimators': [100, 150],
        'learning_rate': [0.05, 0.1],
        'max_depth': [3, 4]
    }
}

# 2. for — har bir model bo'yicha alohida GridSearchCV o'tkazamiz
best_tuned_results = []
for name, model in models.items():
    print(f"\n🔍 {name} uchun tuning...")
    grid = GridSearchCV(
        estimator=model,
        param_grid=param_grids[name],
        cv=5,               # 5-fold cross-validation
        scoring='roc_auc',  # asosiy mezoni
        n_jobs=-1           # barcha CPU yadrolari
    )
    grid.fit(X_train_scaled, y_train)

    best_model = grid.best_estimator_
    y_pred  = best_model.predict(X_test_scaled)
    y_proba = best_model.predict_proba(X_test_scaled)[:, 1]

    best_tuned_results.append({
        "Model": name,
        "Best Params": str(grid.best_params_),
        "Accuracy":  accuracy_score(y_test, y_pred),
        "ROC-AUC":   roc_auc_score(y_test, y_proba),
        "F1-Score":  f1_score(y_test, y_pred)
    })
    print(f"  Eng yaxshi: {grid.best_params_}")
    print(f"  ROC-AUC={roc_auc_score(y_test, y_proba):.4f}  F1={f1_score(y_test, y_pred):.4f}")

# 3. Natijalarni jadvalga o'tkazamiz
df_tuned = pd.DataFrame(best_tuned_results)
print("\n--- TUNED MODEL RESULTS ---")
print(df_tuned.to_string(index=False))
